# Support

For reproducible defects, use the bug-report form with a minimal synthetic CSV, exact CLI command, application/Python versions and sanitized error code. For design changes, use the feature form with acceptance criteria and compatibility considerations.

Before reporting an operational issue, consult docs/OPERATIONS.md and docs/CLI_REFERENCE.md. Never attach API keys, real workload databases, private rows or unredacted provider traces. Security issues follow SECURITY.md rather than public issues.

This is a maintained reference project without a contracted support service, response SLA or on-call team. Repository ownership and review routing are recorded in .github/CODEOWNERS; that file does not imply enterprise staffing.
